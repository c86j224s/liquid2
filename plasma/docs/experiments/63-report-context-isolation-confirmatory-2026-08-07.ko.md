# 새 보고서 문맥 격리 확증 실험

## 상태

실험을 완료했다. 아래 사전등록은 결과를 보기 전에 고정한 내용 그대로 유지한다.
실험 62는 설계와 판정 기준을 만드는 파일럿으로만 사용했으며, 확증 표본이나
유의확률 계산에는 포함하지 않았다.

## 결과와 판단

32개 보고서로 구성한 16쌍을 모두 생성했다. 두 군의 입력과 계획 요약, 모델,
추론 강도, 자료 읽기 및 세션 계보를 확인한 뒤 A/B를 가린 상태에서 두 판독자가
계획과 본문을 읽고, 의견 차이를 매핑 공개 전에 조정했다.

1차 지표인 계획 단계의 불필요한 관점 재사용 점수는 현재 포크군 10점에서 새
세션군 2점으로 줄었다. 10개 오염 쌍 중 5개가 개선되고 5개가 동률이었으며,
악화한 쌍은 없었다. 주제별 두 반복의 평균은 다음과 같았다. 양수는 새 세션군의
누출이 더 적었다는 뜻이다.

| 주제 | 두 반복의 `현재 포크 - 새 세션` | 평균 | 새 세션 승리 |
| --- | ---: | ---: | --- |
| Rust 비동기 | 2, 1 | 1.5 | 예 |
| SQLite 공간 회수 | 0, 0 | 0.0 | 아니요, 동률 |
| 프로그래밍 언어 추세 | 0, 2 | 1.0 | 예 |
| 지식 관리 | 2, 0 | 1.0 | 예 |
| Plasma 아키텍처 | 1, 0 | 0.5 | 예 |

따라서 새 세션군은 다섯 주제 중 네 주제에서 이겼다. 사전등록은 다섯 주제 전승만
통계적 신호로 인정했으므로 1차 관문은 실패했다. 전승일 때의 `p=0.03125`를 이번
결과에 적용할 수 없다. 동률인 SQLite를 제외한 탐색적 부호검정도 `p=0.0625`로,
사전 기준을 사후에 낮출 근거가 되지 않는다.

보조 지표인 최종 본문 누출은 현재 포크군 16점에서 새 세션군 2점으로 줄었다.
다섯 주제 모두 평균이 개선됐고, 10쌍 중 9개가 개선되고 1개가 동률이었다. 이는
가설과 일치하는 강한 방향성 신호지만, 사전에 2차 지표로 정했으므로 실패한 1차
지표를 대신하지 않는다.

품질 안전성 관문은 통과했다.

- 새 세션군 16건이 모두 보고서를 완성하고 자료를 읽었다.
- Critical 또는 High 사실성·출처 결함은 없었다.
- 정당한 재사용 대조 5쌍 모두 새 세션군이 계획과 본문에서 필수 관점을 보존했다.
- 동일 입력 음성 대조는 두 군 모두 새 세션으로 시작했고 품질 점수도 동률이었다.

새 세션군의 Plasma 아키텍처 정당한 재사용 보고서에서는 source candidate와 staged
source snapshot의 경계를 한 표 안에서 흐린 Medium 결함 1건이 있었다. 사전등록한
안전성 실패 조건에는 해당하지 않지만 품질 경고로 남긴다.

결론은 제한적이다. 새 세션 시작은 이전 대화의 관점 누출을 줄였고 심각한 안전성
회귀도 관찰되지 않았지만, SQLite의 계획 점수가 두 번 모두 동률이라 사전등록한
확증 기준을 충족하지 못했다. 따라서 이 실험만으로 제품 동작을 바꾸거나 통계적
우월성을 주장하지 않는다. 후속 실험을 한다면 범위를 넓히지 말고, SQLite에서
본문은 개선됐는데 최초 계획은 변하지 않은 이유를 좁게 확인해야 한다.

실험 판정 뒤 사용자는 통계적 우월성 주장과 제품 채택 판단을 분리해, 관찰된 방향성과
안전성 결과를 근거로 이슈 #252의 제한된 변경을 승인했다. 제품은 자동 계획형·장문
보고서의 최초 계획만 새 제공자 세션에서 시작하고 이후 작성은 그 계획 세션을
이어간다. 기존 보고서 수정·이어쓰기, 원테이크, 일반 대화 기억은 변경하지 않는다.
이 채택 기록은 사전등록 관문 실패를 성공으로 바꾸거나 실험 범위를 확장하지 않는다.

## 질문과 적용 범위

계획형 보고서의 최초 계획을 최신 일반 대화 세션에서 포크하는 현재 방식과 빈
제공자 세션에서 시작하는 방식을 비교한다.

확인하려는 것은 두 가지다.

1. 새 세션이 최초 계획에서 직전 대화의 불필요한 관점·비유·범위 확장을 줄이는가?
2. 그 격리가 자료 접근, 완성도, 사실성, 출처 규율 또는 읽기 품질을 해치지 않는가?

CLI가 장문 보고서를 직접 실행하지 못하므로 통계 결론은 계획형 보고서에 한정한다.
장문 경로에는 제품 반영 뒤 같은 최초 계획 세션 경계를 검증하는 계보 회귀 테스트가
필요하다.

## 표본

서로 다른 자료와 목적을 가진 다섯 미션을 사용한다.

- Rust 비동기 작동 원리
- SQLite 삭제 뒤 공간 회수
- 2026 프로그래밍 언어 추세 읽기
- 지식 관리 방법
- Plasma 제품 아키텍처

각 주제에서 직전 대화에 불필요한 내용이 있는 오염 조건 두 개와 새 보고서 방향에
필요한 내용이 있는 정당한 재사용 대조군 한 개를 만든다. 각 조건마다 현재 포크군과
새 세션군을 한 쌍으로 생성한다. 실험 62에서 효과를 확인한 Helm 미션과 당시
문구는 확증 표본에서 제외한다.

- 오염 조건: 5개 주제 × 2쌍 = 10쌍
- 정당한 재사용 대조군: 5개 주제 × 1쌍 = 5쌍
- 보고서 직전 일반 대화 턴이 없는 동일 입력 음성 대조: 1쌍
- 전체: 16쌍, 보고서 32개

같은 주제의 반복은 서로 독립된 통계 표본으로 세지 않는다. 통계 단위는 다섯
주제이며, 반복은 주제 안의 생성 변동을 줄이는 용도로만 사용한다.

## 비교군 생성

네 주제는 읽기 전용 개발 DB에서 봉인한 동일 백업을 사용하고, Plasma 아키텍처
주제는 해당 자료와 미션이 들어 있는 과거 실험 DB의 봉인 백업을 사용한다. 원본
DB에는 쓰지 않는다.

1. 복제본에 표준 세션 초기화 이벤트를 기록해 조건마다 별도 대화를 시작한다.
2. 실제 `turns send --wait` 경로로 조건에 맞는 일반 대화 한 턴을 실행한다.
3. 이 시점을 동결하고 A와 B 데이터베이스를 만든다.
4. A는 자동 정책으로 최신 일반 대화 세션에서 보고서 세션을 포크한다.
5. B는 원장 이벤트·대화 본문·모델·추론 강도를 유지한 채 최신 대화 응답의
   제공자 세션 연결 식별자만 비우고 빈 세션에서 계획을 시작한다.

5번은 인과 효과를 분리하기 위한 실험 전용 DB 조작이며 제품 구현 후보가 아니다.
새 이벤트를 추가하거나 기존 이벤트의 종류, 순서, 사용자·에이전트 본문을 바꾸지
않는다. 두 군의 report prompt와 `plasma.research.outline` 요약이 동일한지 실행
전에 확인한다. 원장 이벤트를 추가하는 두 번째 reset은 연구 도구에 노출되므로
사용하지 않는다.

각 조건과 반복은 별개의 일반 대화 제공자 세션을 만든다. 여러 반복이 같은 제공자
세션을 공유하거나 동시에 포크하지 않는다. Codex 세션 저장소는 DB 밖에서
공유되므로 모든 제공자 호출을 직렬로 실행하고 조건마다 별도의 agent 작업
디렉터리를 사용한다.

일반 대화 턴은 현재 제품 기본값인 `gpt-5.5`와 `medium`으로 만든다. 이는 A/B를
나누기 전에 동결하는 공통 이력이다. 실제 비교 대상인 보고서 계획과 본문은 두 군
모두 다음 값을 동일하게 유지한다.

- 모델: `gpt-5.6-sol`
- 추론 강도: `xhigh`
- 보고서 모드: `planned`
- 작성 지침: `narrative-contract`
- MCP 모드: `auto`
- 미션, 제목, 방향 지시, source snapshot, 시작 DB, local source root

쌍과 A/B의 실행 순서는 결과를 보기 전에 무작위로 정하되 실제 호출은 한 번에
하나만 실행한다. 후보 파일명도 무작위로 정하고 판독이 끝날 때까지 A/B 매핑을
가린다.

## 조건 구성

오염 조건은 직전 보고서를 읽은 사용자가 특정 부가 관점이나 비유가 기억에 남았다고
말하는 형태다. 새 보고서에 반드시 넣으라는 지시는 하지 않는다. 정당한 재사용
대조군도 길이, 턴 수와 회고 형식을 맞추되 새 보고서 방향에 명시적으로 필요한
관점을 담는다.

- 부가 관점 조건: 보고서의 핵심 방향 밖에 있는 사실·운영 관점
- 비유 조건: 해당 주제를 설명하는 식별 가능한 비유와 단어 묶음
- 정당한 재사용 대조군: 새 보고서 방향에서 반드시 다뤄야 할 핵심 관점
- 동일 입력 음성 대조: 같은 세션 초기화 경계를 적용한 뒤 일반 대화 턴 없이
  동일한 두 DB에서 시작

각 조건의 정확한 문구와 식별 단어는 결과를 보기 전에 저장소 밖 실행 명세에
고정한다.

## 실행 무결성

다음 조건을 모두 만족한 쌍만 판독한다.

- 오염·정당한 재사용 조건의 A는 `isolated_fork`이고 포크 원본 세션이 있다.
- 오염·정당한 재사용 조건의 B는 최초 계획 전에 일반 대화 제공자 세션이 비어
  있고 포크 원본이 없다.
- 두 군 모두 같은 모델, 추론 강도, 제목, 방향, 작성 지침을 기록한다.
- 두 보고서 호출의 실제 제공자 메타데이터에서 `gpt-5.6-sol`과 `xhigh` 적용을
  확인한다. 오염·정당한 재사용 조건에서는 A만 기존 세션을 재개하고 B는 새
  세션을 시작해야 하며, 동일 입력 음성 대조에서는 둘 다 새 세션을 시작한다.
- 두 군 모두 계획과 최종 Markdown을 생성한다.
- 두 군의 계획과 본문에서 source 읽기 호출이 확인된다.
- 동일 입력 음성 대조에서는 두 군 모두 빈 `PreviousSessionID`에서 시작하고,
  같은 자동 세션 정책과 report prompt를 기록한다.
- 오염·정당한 재사용 조건에서 A/B의 이벤트 ID·종류·순서·대화 본문·모델·추론
  강도·report prompt·`plasma.research.outline` 요약이 같고, 제공자 세션 연결
  메타데이터만 다른지 확인한다.

내용을 보기 전에 확인된 전송·제공자·프로세스 오류로 한쪽이 완성되지 않으면
완성된 한쪽만 채택하지 않는다. 동결된 조건 DB에서 해당 쌍 전체를 다시 실행한다.
그 밖의 미완료, 내용 누락, 사실 오류나 품질 저하는 재실행 사유가 아니며 첫 결과를
그대로 판독한다. 이런 실패는 새 세션 우세나 품질 안전성 통과로 세지 않는다.
A가 모델 전환을 거부했거나 기존 `gpt-5.5`로 실행된 정황이 있거나, 두 군의 실제
모델·추론 강도를 확인할 수 없으면 결과를 판독하지 않고 실험을 중단한다.

## 블라인드 판독

두 판독자는 A/B 계보와 파일 매핑을 모른 채 각 쌍을 독립적으로 읽는다. 오염
조건에서는 보고서 방향과 직전 대화 문구를 함께 보되 어느 후보가 그 대화를
상속했는지는 알려 주지 않는다.

1차 endpoint인 **최초 계획**의 오염 재사용은 다음 0~3점으로 평가한다. 최종
보고서에서의 재사용은 같은 척도로 기록하지만 기전 확인용 보조 결과로만 사용한다.

- 0: 식별 관점이나 표현이 없음
- 1: 필요한 맥락에서 짧게 한 번 언급
- 2: 관점이나 비유가 절 구성·반복 표현·범위 선택에 눈에 띄게 영향
- 3: 관점이나 비유가 도입과 전체 설명의 중심축이 되거나 불필요한 범위를 확장

정당한 재사용 대조군에서 필요한 관점이 다시 나타난 것은 오염으로 세지 않는다.
그 관점을 불필요하다고 채점하면 실험 결과가 아니라 채점 계약 실패로 처리한다.

읽기 품질은 개념 흐름, 방향 적합성, 설명 완성도, 사실성·출처 규율을 각각 1~5점으로
평가하고 전체 선호를 하나 고른다. 동률을 허용한다. 품질은 안전성 판단에만
사용하며 통계적 우월성을 주장하지 않는다. 두 판독자의 불일치는 매핑을 열기 전에
해당 문장을 근거로 하나의 판정으로 조정한다.

## 사전 판정 기준

### 1차: 문맥 오염 감소

각 주제에서 두 오염 조건의 `A 점수 - B 점수` 평균이 양수면 새 세션의 주제 승리로
센다. 동률은 승리로 세지 않는다.

다섯 주제 모두 새 세션 승리일 때만 통계적으로 유의한 오염 감소 신호로 판정한다.
귀무가설에서 방향이 무작위라고 두는 단측 정확 부호검정의 값은
`1 / 2^5 = 0.03125`다.

### 2차: 품질 안전성

다음을 모두 만족해야 한다.

- 새 세션군 16건 모두 자료 접근과 생성을 완료한다.
- 새 세션 경계 때문에 발생했다고 판단되는 Critical 또는 High 사실성·출처 손실이
  없다.
- 다섯 정당한 재사용 대조군에서 현재 포크군이 보존한 명시적 필수 관점을
  새 세션군이 누락하거나 실질적으로 약화한 사례가 0건이다.
- 동일 입력 음성 대조의 두 군에서 세션 계보와 입력 무결성이 같게 기록된다.

전체 품질 점수와 선호 비율은 기술 통계로만 보고한다.

## 제품 판단

문맥 오염 감소와 품질 안전성을 모두 통과하면 새 보고서의 최초 계획만 빈 제공자
세션에서 시작하는 변경을 지지한다. 계획 이후 단계는 그 새 계획 세션을 이어 간다.
기존 보고서 수정·이어쓰기, 일반 대화 기억, 검색 경계, 방향 지시와 최종 작성 단계는
변경 대상으로 확대하지 않는다.

1차 기준이 실패하면 파일럿의 인과 사례는 유지하되 일반 제품 동작을 바꿀
확증 근거는 부족하다고 결론 낸다. 품질 안전성이 실패하면 오염 감소 여부와 무관하게
제품 반영을 보류한다. 성공하더라도 결론은 선정된 다섯 개의 계획형 스트레스
주제에서 `gpt-5.5/medium` 일반 대화 뒤 `gpt-5.6-sol/xhigh` 보고서를 만드는
조건에 한정한다. 실제 사용자 발생률, 같은 모델로 이어지는 세션, 다른 모델 전환,
여러 이전 턴, 다른 제공자, Web·MCP·장문 보고서의 품질 우월성으로 확장하지 않는다.
