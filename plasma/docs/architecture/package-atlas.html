범위와 읽는 방법
  • go list ./... 기준 darwin/arm64 기본 build에서 확인된 111개 Go 패키지. 다른 디렉터리: 없음 (Go 파일이 있는 모든 디렉터리가 포함됨).
  • 소스 주석과 파일 목록을 포함합니다. Go 파일별 import를 합친 패키지 간 직접 연결이며 전이 의존성은 선으로 추가하지 않았습니다.
  • 테스트 전용 의존은 실행 코드의 선과 혼합하지 않습니다. 테스트 파일 및 build 제외 파일은 상세에 별도 표시합니다.
  • 브라우저 UI는 internal/web/static/의 JS·CSS·HTML이며 별도 Go 패키지가 아닙니다. Web 패키지에서 파일을 embed합니다. 이 문서는 JS 모듈 의존성 지도는 아닙니다.
  • Go 표준 라이브러리와 외부 모듈도 패키지 상세에서 조회할 수 있습니다. 외부 코드의 내부 구조는 이 문서 범위 밖입니다.
  • 파일 링크는 동일 checkout의 소스를 가리킵니다. HTML만 단독 복사해도 지도·검색은 동작하지만 상대 소스 링크는 소스 트리가 있어야 열립니다.
  • 갱신: Plasma 루트에서 python3 scripts/generate-package-atlas.py. 패키지 inventory와 import는 다시 수집되며, 수동 역할 설명은 스크립트의 사전에 유지됩니다.
